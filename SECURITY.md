# Security Policy

## Supported catalog

Security fixes target the current catalog on `main` and its immutable release
references.

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/fab7hq/ext-registry/security/advisories/new).
Include the affected catalog entry, exact release URL or digest, impact, and a
sanitized reproduction. Do not open a public issue for an unpatched
vulnerability.

Catalog inclusion means the entry passed structural review and binds an exact
source digest. It is not a semantic correctness or security verdict on an
extension.
